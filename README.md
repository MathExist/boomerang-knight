# 🛡️ Boomerang Knight

Platformer game where you are a knight and throw bouncing swords at gloams (enemies).

**Live Demo: ** https://mathexist.itch.io/boomerang-knight

**Current Version: ** 1.0

1. Click the play button on the start page:

![start page](docs/assets/startpage.png)

2. Kill as many gloams as possible using bouncing swoards while maintaining health.
